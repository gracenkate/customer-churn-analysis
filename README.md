# Customer Churn Analysis

## Overview

This project analyzes customer churn using Python, SQL, and statistical analysis.

## Objectives

- Explore patterns in customer churn
- Identify factors associated with churn
- Quantify differences between customer groups
- Communicate findings through data visualizations
- Develop data-driven recommendations

## Tools

- Python
- Pandas
- SQL
- PostgreSQL
- Matplotlib / Seaborn
- Statistical analysis
